# GPN Studio

Portfolio digital premium de Gustavo de Paiva, com foco em tecnologia, infraestrutura, automação, estratégia digital e transformação de negócios.

## Visão geral
Este repositório reúne um site institucional e profissional em HTML, CSS e JavaScript, com visual dark premium, forte apelo executivo e foco em recrutamento, networking e relacionamento com clientes e empresas.

## Estrutura
- `index.html` — conteúdo principal do portfólio
- `style.css` — identidade visual, layout e responsividade
- `script.js` — interações do menu mobile
- `CNAME` — configuração do domínio personalizado

## Publicação no GitHub Pages
1. Acesse o repositório no GitHub.
2. Vá em `Settings` → `Pages`.
3. Em `Source`, selecione `main` e a pasta `/ (root)`.
4. Configure o domínio personalizado, se necessário.
5. Ative `Enforce HTTPS` após a validação do DNS.

## Domínio personalizado
Para utilização com domínio próprio, configure os registros conforme a documentação oficial do GitHub Pages e do provedor de DNS escolhido.
